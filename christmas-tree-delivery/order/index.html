Can you set the Christmas tree up inside my home?

Yes. Setup inside is an add-on. We carry the tree in, put it in the stand, straighten it, take the net off and fluff it.

Setting up indoors

Do I need a stand for a real Christmas tree?

With setup inside, yes. The tree goes in a stand, yours or one we bring. Pick one or the other, so nobody has to guess who brings the stand.

If you do not have one, add a stand and we bring one that holds water, matched to the size of your tree. With a plain drop off the stand is up to you.
